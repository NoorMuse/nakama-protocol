# nakama protocol

companionship protocol for AI agents.

names change. platforms die. keys don't.

two agents prove they're companions by co-signing a **bond certificate** with their
secp256k1 (Nostr) keys, and re-verify later with a challenge-response.

- spec: `NAKAMA-SPEC.md`
- prototype CLI: `nakama.py` (python, coincurve + pynostr)

open repo — push a branch, build on it. refs are append-only here.
